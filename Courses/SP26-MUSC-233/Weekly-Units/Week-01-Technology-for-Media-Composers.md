# Week 01: Technology for Media Composers

## Overview

This week introduces the essential technology landscape for composers working across all media types. We'll explore the tools, pipelines, and workflows used in film, television, games, podcasts, and other media, establishing a foundation for the technical skills developed throughout this course.

## Learning Objectives

By the end of this session, students will be able to:

- Identify the key tools and technologies used by media composers across different industries
- Describe the differences between linear and interactive audio workflows
- Configure their DAW session settings for professional media production
- Explain common delivery formats and specifications across media types

## Topics Covered

### The Modern Media Composer's Toolkit

**Core Software**
- DAW (Logic, Pro Tools, Cubase, Ableton, etc.)
- Notation software (Sibelius, Dorico, Finale)
- Sample libraries and virtual instruments
- Audio middleware (FMOD, Wwise) - for interactive media

**Support Tools**
- Stem management and organization
- Reference track tools
- Collaboration platforms (Dropbox, Google Drive, Frame.io)
- Communication tools (timecode, session notes)

### Linear vs. Interactive Workflows

**Linear Media (Film/TV/Podcasts)**
- Locked picture and timecode
- Cue sheets and spotting sessions
- Stems and deliverables
- Mix stages and dubbing

**Interactive Media (Games/Apps)**
- Non-linearity and player agency
- Adaptive/reactive audio concepts
- Memory and performance considerations
- Middleware and engine integration

### Industry Delivery Standards

**Audio Specifications**
- Sample rates: 48kHz (broadcast), 44.1kHz (music), 96kHz (archival)
- Bit depth: 24-bit standard, 16-bit final delivery
- File formats: WAV, AIFF, MP3, AAC, OGG

**Stem Organization**
- What stems are and why they matter
- Common stem configurations
- Naming conventions
- Metadata and documentation

### DAW Setup for Media Work

- Project settings and templates
- Track organization strategies
- Color coding and naming conventions
- Export presets for different deliverables

## In-Class Activity

**Media Composer Toolkit Audit**

**Part 1: Tool Inventory (20 min)**
1. Document your current audio production toolkit:
   - Primary DAW and version
   - Virtual instruments you own/use regularly
   - Effects plugins you rely on
   - Any notation software
2. Identify gaps: What tools might you need for professional work?
3. Share findings with the class

**Part 2: DAW Session Template (40 min)**

Create a professional session template in your DAW:

1. **Project Settings**
   - Set to 48kHz/24-bit (broadcast standard)
   - Configure tempo and time signature

2. **Track Organization** (create track groups/folders):
   - Strings
   - Brass
   - Woodwinds
   - Percussion
   - Synths/Electronic
   - FX/Sound Design
   - Reference Track (muted by default)

3. **Bus Routing**
   - Create submix buses for each section
   - Add a master bus with metering
   - Set up a reference track routing (to compare against)

4. **Export Presets**
   - Full Mix (stereo, 48kHz/24-bit WAV)
   - MP3 Preview (320kbps)
   - Stems preset (separate each bus)

**Part 3: Workflow Discussion (20 min)**

Discuss as a class:
- What media types interest you most as a composer?
- What technical skills do you need to develop?
- How does this course connect to your MUSC 231 projects?
