# Week 03: Advanced Synthesis & Sound Design

## Overview

This week builds on synthesis fundamentals to explore advanced techniques: layering multiple sound sources, complex modulation, and creative processing chains. These techniques form the foundation for professional-quality sound design across all media types.

## Learning Objectives

By the end of this session, students will be able to:

- Layer multiple synthesis elements to create rich, complex sounds
- Apply complex modulation routing for evolving textures
- Design processing chains that enhance and transform sounds
- Create professional-quality sound design elements for media projects

## Topics Covered

### Layering Techniques

**The Layer Approach**
- Sub layer (low-frequency foundation)
- Body layer (mid-range character)
- Transient layer (attack and presence)
- Air/texture layer (high-frequency detail)

**Layering Best Practices**
- Frequency separation between layers
- Phase alignment considerations
- Volume balancing across layers
- When to use mono vs. stereo per layer

### Complex Modulation

**Modulation Sources**
- LFOs with different waveforms
- Envelopes beyond ADSR (multi-stage)
- Envelope followers (sidechain from audio)
- Random/sample-and-hold
- Macro controls for performance

**Modulation Destinations**
- Filter cutoff and resonance
- Oscillator pitch and phase
- Effect parameters (wet/dry, feedback)
- Wavetable position
- Layer volumes and panning

**Modulation Techniques**
- Serial modulation (modulating modulators)
- Cross-modulation between layers
- Tempo-synced modulation
- Key/velocity tracking

### Processing Chains

**Creative Signal Flow**
- Order matters: EQ → Saturation → Compression vs. Compression → Saturation → EQ
- Parallel processing (dry/wet blends)
- Serial effects chains
- Send/return configurations

**Essential Processing Tools**
- Saturation and distortion types
- Multi-band processing
- Transient shapers
- Stereo imaging tools
- Creative reverbs and delays

**Sound Design Processing**
- Pitch manipulation (granular, formant shifting)
- Time stretching creatively
- Convolution with unusual impulse responses
- Feedback and self-oscillation techniques

### Building Sound Design Elements

**Impact Sounds**
- Layering sub, punch, and crack
- Envelope shaping for punch
- Reverb tail design
- Creating variations

**Risers and Transitions**
- Pitch sweeps and filter automation
- Noise sweeps
- Reverse reverb techniques
- Layering for complexity

**Atmosphere and Texture**
- Drone creation
- Movement through modulation
- Spatial design with reverb/delay
- Evolution over time

## In-Class Activity

**Sound Design Construction Workshop**

**Part 1: Layered Impact Sound (25 min)**

Build a cinematic impact from scratch:

1. **Create the Sub Layer**
   - Sine wave with pitch envelope (drop)
   - Short decay (100-200ms)
   - Heavy compression for punch

2. **Create the Body Layer**
   - Noise or sawtooth source
   - Band-pass filter around 200-800Hz
   - Fast attack, medium decay
   - Add saturation

3. **Create the Transient Layer**
   - Noise burst or click
   - Very fast envelope (< 50ms)
   - High-pass filtered
   - Add transient shaper

4. **Combine and Process**
   - Balance levels between layers
   - Add parallel compression
   - Design reverb tail (short room or longer for drama)

**Part 2: Evolving Texture (25 min)**

Create a 30-second evolving drone/texture:

1. **Base Layer**
   - Pad or sustained tone
   - Slow wavetable or filter movement

2. **Movement Layer**
   - Arpeggiated or granular texture
   - Tempo-synced modulation

3. **Detail Layer**
   - High-frequency shimmer or noise
   - Random modulation sources

4. **Processing**
   - Long reverb with modulated parameters
   - Delay with feedback automation
   - Subtle stereo movement

**Part 3: Riser/Transition (25 min)**

Build a 4-8 second tension-building riser:

1. **Noise Sweep**
   - White/pink noise
   - High-pass filter opening over time
   - Volume automation

2. **Pitch Element**
   - Rising tone or chord
   - Pitch bend automation
   - Consider adding vibrato that increases

3. **Processing Automation**
   - Reverb increasing
   - Distortion increasing
   - Stereo width expanding

**Deliverable:**
Three sound design elements (impact, texture, riser) rendered as 48kHz/24-bit WAV files.
