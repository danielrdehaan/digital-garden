# Studio Session - Week 05 (Solo)

## Session Type: Solo Studio

Individual focused work time for DAW exploration and deep-dive learning.

## Session Focus

Following Monday's lecture on DAW features, this session is dedicated to **exploring your DAW** in depth. Discover features you've never used and optimize your workflow.

## Session Structure

| Time | Activity |
|------|----------|
| 0:00-0:10 | Set exploration goals |
| 0:10-0:55 | Deep DAW exploration |
| 0:55-1:10 | Document discoveries |
| 1:10-1:20 | Optional share-out |

## Today's Goals

By the end of this session, you should have:

1. **Learned at least 5 new features** in your DAW
2. **Practiced new keyboard shortcuts**
3. **Started or updated a production template**
4. **Documented your discoveries** for the assignment

## Exploration Suggestions

### Features to Explore

- Automation curves and modes
- MIDI effects/transformers
- Audio quantization/warping
- Project organization tools
- Key commands you've never tried
- Built-in plugins you've ignored

### Workflow Optimizations

- Create a custom template
- Set up track groups/folders
- Configure default plugins
- Customize your workspace layout

### Learning Resources

Use your DAW's built-in help, online documentation, or video tutorials to guide exploration.

## Documentation Prompts

- What new features did I discover?
- Which shortcuts will I actually use?
- How will this change my workflow?
- What do I want to explore more?
