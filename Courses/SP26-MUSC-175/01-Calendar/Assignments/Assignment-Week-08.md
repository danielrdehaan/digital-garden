# Assignment - Week 08: Sound Design Portfolio

**Due:** Sunday, March 22, 2026 @ 11:59 PM

## Overview

Create a mini sound design portfolio with at least 5 original sounds, demonstrating range and intentionality in your synthesis approach.

## Deliverables

Submit to Canvas:

### 1. Sound Design Portfolio

Create **at least 5 original sounds** in Vital:

**Required categories (at least one each):**
- Bass (sub, mid-range, or aggressive)
- Lead (pluck, sustained, or arpeggio-friendly)
- Pad/Texture (ambient, evolving, or rhythmic)

**Plus 2+ additional sounds of your choice:**
- Drum/percussion sounds
- Sound effects
- Experimental textures
- Genre-specific sounds

### 2. Portfolio Documentation

Create a portfolio document that includes:

**For each sound:**
| Sound Name | Category | Description | Key Techniques Used |
|------------|----------|-------------|---------------------|
| | | | |

**Overall reflection (200-300 words):**
- What synthesis techniques did you explore?
- Which sound are you most proud of and why?
- What challenged you most?
- What do you want to learn more about?

### 3. Audio Demos

Create a single audio file showcasing all sounds:
- Play each sound briefly (5-10 seconds)
- Include the sound name spoken or written (optional)
- Total length: 1-2 minutes
- Name: `LASTNAME_Week08_Portfolio.wav`

### 4. Patch Files

Export all Vital patches with clear naming.

### 5. Habit Check-In

Continue your weekly habit documentation.

**Note:** This is the last assignment before Spring Break!

## Rubric

| Criteria | Excellent (90-100%) | Good (80-89%) | Adequate (70-79%) | Needs Work (<70%) |
|----------|---------------------|---------------|-------------------|-------------------|
| **Quantity/Variety** | 5+ distinct, high-quality sounds | 5 sounds with good variety | 5 basic sounds | Fewer than 5 or too similar |
| **Quality** | Professional-sounding, usable | Good quality | Adequate quality | Poor quality |
| **Documentation** | Clear, insightful portfolio | Good documentation | Basic documentation | Missing or unclear |
| **Habit Check-In** | Complete and insightful | Adequate | Basic | Missing or minimal |
