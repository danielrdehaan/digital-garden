## Description

This sample library is a lite version of [Venus Theory’s fantastic Stella library](https://www.decentsamples.com/product/stella-by-venus-theory/).

Stella is a sample library of my 1950’s Gibson LG-0 named ‘Stella ‘ from the name carved into the body, and printed on the headstock. Stella is a rough old guitar I received in completely broken condition. After a fair bit of work I was able to somewhat restore it to a playable state and found it has a rich and aged sound, with a very unique folky tone.

Because I’m not sure how long it would last if I played it regularly before the glue and everything else gave out and it would be gone for good I figured I would immortalize it with a sample library so that everyone can enjoy this wonderfully weird guitar.

What’s inside:

- 1 DS Library File
- 4 Multisampled Sound Sets
- 4 Instrument Presets

This sample library works with the free **Decent Sampler** player plugin. Download it [here](https://www.decentsamples.com/product/decent-sampler-plugin/).
