## Description

This instrument consists of 11 patches recorded from Dave’s ever-changing modular synth. Some of the tones were generated using Mutable Instruments Plaits, others by Disting MK4.

This Decent Sampler version of this library works with the free **Decent Sampler** player plugin. Download it [here](https://www.decentsamples.com/product/decent-sampler-plugin/).

Specs:

- Sample rate: 24-bit 48khz
- Library size: 206MB
