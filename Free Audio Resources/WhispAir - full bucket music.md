WhispAir is a software instrument for Microsoft Windows (VST) and Apple macOS (VST/AU). It is written in native C++ code for high performance and low CPU consumption. Main features are:

- All parameters on one single page
- Three flexible wavetable oscillators
- Classic Full Bucket stereo filter
- Three modulation and four envelope generators
- Unison mode and Chorus
- TUN/SCL/KBL micro-tuning file import
- Supports [MTS-ESP by ODDSound](https://oddsound.com/) dynamic micro-tuning
- Resizable user interface (not "N" version!)
- MIDI Learn – all parameters can be controlled by MIDI CC
- Plug-in supports Windows and macOS (32 bit and 64 bit)

Note: **Audio-Term** (Windows only) is a great tool which I used to create many of WhispAir's built-in wavetables. For more information see the [Audio-Term Facebook page](https://www.facebook.com/audioterm/).
