Our free snare drum plugin features ultra-realistic sound through physical modeling. Use MIDI notes to trigger the in-built exciter and change tip hardness and rimshot parameters. For added realism the MIDI triggered values can be adjusted with a bell shaped probability curve. The exciter feeds into a waveguide resonator algorithm which lets you change drumhead tuning, snares tension and hit position.

### System Requirements

64-bit VST3 and AU plug-in. Requires a 64 bit CPU and Operating System.

### **Hardware**

Minimum System :

- Memory : 4 GB RAM, we recommend at least 8 GB.
- Free disk space for installation : ~25MB

### Operating Systems

- **Mac OS 10.12** and greater (M1 processors are compatible for the VST3, but for using the AU in Logic you will need to run Logic in Rosetta mode)
- **Windows 10** (other versions untested)
- **Linux** (64 bit Intel/AMD processors, tested in Ubuntu 21.04, there is no reason why it wouldn’t run on any other distro/version)

### Plugin Hosts / Digital Audio Workstations

Any **V**irtual**S**tudio**T**echnology v**3** or **A**udio**U**nit compatible plugin host should work. We have tested:

- Ableton **Live** 10.1 and greater
- **Bitwig** 3.3 and greater (earlier versions untested)
- **Reaper** 6.28 and greater (earlier versions untested)
- **Ardour** 6.5 and greater
- **Cantabile**
- **Cubase** (user reported it working)
- **PlogueBidule** (user reported it working)
- **Cakewalk** by BandLab (PRO version: see below how to configure Cakewalk)
- MOTU **Digital Performer**
- Apple **GarageBand **and** Logic** (for Logic on M1 hardware you must enable Rosetta mode)
- Other DAWs or plugin hosts which support VST3 plugins should work but are not tested. Reports are welcome.

### What isn’t working

The audio sidechain of the PRO version is not working due to an [incomplete VST3 support](https://forums.steinberg.net/t/signal-sidechains-in-vst3i-not-all-hosts-support-it/736622/2) in

- Samplitude
- Presonus Studio One
