### Rack 2 System Requirements

- Windows 7–11, macOS 10.9–12.0, or Linux (such as Ubuntu 16.04+)
- CPU: Intel/AMD 64-bit processor supporting SSE4.2 (2011 or later)
- Graphics: Dedicated Nvidia/AMD graphics card from 2013 or later with recent driver update 
    - Integrated (non-dedicated) graphics such as Intel HD are not recommended and may cause significantly increased CPU usage.
- Memory: 1 GB
- Disk space: 1 GB

### DAW plugin requirements (Rack 2 Pro only)

In addition to the *Rack 2 System Requirements*:

- Plugin compatibility: VST 2.x 64-bit
- Supported DAWs: Ableton Live 9–11, Cubase 11, FL Studio 20, Reason 10-12, Bitwig 4, Reaper 6, Mixbus 6, Studio One 5, Cakewalk

### Apple Silicon (ARM, e.g. M1, M1 Pro)

Rack 2 standalone can run on Apple ARM via Apple’s Rosetta 2.
 Rack 2 plugin versions require an Intel 64-bit DAW or an ARM DAW that supports loading Intel 64-bit plugins.
