**Bob Perry Gate 2** is the new ideal way of making the best of your signal. Real Side Chaining and the choice between three distinct, smooth sounding algorithms make **Bob Perry Gate 2** a supreme audio plug-in.

Perfect for bringing that noise level down, be it for Drums, Vocals, Guitars, or just to be creative.

### New Features:

## Description

### New features:

- Real Sidechaining
- Easy-to-use Graphical User Interface
- Switchable Response Algorithm
- Input, Output and Gain Reduction Metering
- Numeric Data Input
- Windows and macOS support
- HiDPI and Retina Display support
- One Purchase gives you access to all versions: 
    - Windows VST3 64 bit + 32 bit (x86)
    - Windows VST2 64 bit + 32 bit (x86)
    - Windows AAX (64 bit)
    - macOS VST3
    - macOS AAX
    - macOS AU (Audio Unit)

### Specifications:

- Input and Output Gain from -24dB to +24dB
- Attack, Hold and Release: 0ms / .1ms to 500ms
- Range / Gain Reduction from -144dB to 0dB

### Supported Hosts (Windows):

- Steinberg Cubase 7 and above
- Steinberg Nuendo 6 and above
- Adobe Audition CS6 and newer
- FL Studio 11 and above
- Presonus Studio One v2 and above
- Avid Pro Tools 11 and above

### Supported Hosts (Mac):

- Steinberg Cubase 7 and above (VST3)
- Steinberg Nuendo 6 and above (VST3)
- Adobe Audition CC (VST3)
- Logic Pro X and GarageBand (AU)
- Avid Pro Tools 11 and above
- and many more
- *) due to limitations with the AAX platform,– only mono aux signals are supported– the maximum lookahead value may be lower.*
