The Deputy Mark II is a software instrument for Microsoft Windows (VST) and Apple macOS (VST/AU) in the tradition of classic string machines and early "polyphonic" synthesizers, written in native C++ code for high performance. The main features are:

- Polyphonic string/synthesizer () section and monophonic synthesizer () section
Poly
Mono
- Built-in Ensemble and Phaser effects
- Flexible keyboard assignment for  and  section
Poly
Mono
- Double precision audio processing
- All parameters can be controlled by MIDI controllers
- Exchangeable graphics (for individual skinning)
- Plug-in supports Windows and macOS (32 bit and 64 bit)

On the track ["Deputy"](https://www.fullbucket.de/music/index.html), the Deputy Mark II is the only audio source (plus some delay, reverb and slight compression).
