## Description

![[Screen-Shot-2022-03-18-at-2.51.59-PM.png]]

The melancholic sound of a piano filtered through a portable reel to reel tape recorder from the 60s.

Features:

- Warble knob to select between two takes
- Adjustable tape hiss layer
- Adjustable shimmer layer (ooh!)
- Tone knob
- Chorus effect
- Reverb effect

This library works with the free **Decent Sampler** player plugin. Download it for free [here](https://www.decentsamples.com/product/decent-sampler-plugin/).

Specs:

- Sample rate: 24-bit 48khz
- Library size: 25MB
