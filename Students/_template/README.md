# Student Folder Template

This template shows how to organize your contributions to the Digital Garden.

## Creating Your Folder

1. Copy this `_template` folder
2. Rename it to your name (e.g., `Jane-Smith` or `jsmith`)
3. Delete this README and replace it with your own

## Suggested Folder Structure

```
YourName/
├── README.md           ← Brief intro about yourself and your notes
├── Notes/              ← Your personal study notes
├── Projects/           ← Documentation from your projects
└── Resources/          ← Helpful resources you've found
```

## Your README.md

Create a simple README with:
- Your name
- What topics you're focusing on
- Any relevant links (portfolio, social media, etc.)

## Naming Conventions

- Use **kebab-case** for file names: `my-awesome-note.md`
- Use **Title Case** for note titles inside files
- Add relevant tags from the vault's tag system (see main README)

## Adding Your Notes

1. Create your folder following the structure above
2. Add your notes as Markdown files (`.md`)
3. Use tags to make your notes discoverable
4. Commit and push your changes

## Tips

- Keep file names descriptive but concise
- Link to related notes in the main Knowledge Database when relevant
- Use the vault's existing tag hierarchy for consistency
- Pull from main before pushing to avoid conflicts
