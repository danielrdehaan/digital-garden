# Situation

With only a few requests for final tweaks, the client is happy with what you have created for them and wants you to turn the “elemental with wind chimes” into a 5-minute version that loops seamlessly. They asked that you make it mostly environmental with just a few little musical swells and touchpoints. The wind chimes should feel more like a part of the environment than the music.

# Creative Brief

Transform your **environmental with wind chimes** composition into a 5-minute version that loops seamlessly.

# File Format & Standards

When you are done composing, make sure that your tracks final volume level and between `-1` and `-6 dB`. Then, export it as a `.WAV` file with a **sample rate** of `48000` and a **bit depth** of `24` using the naming convention described below.

# Naming Convention

Your file should be named exactly as follows:

`SP24-MUSC-228_W03_P1-03_FirstName-LastName_Musical-Loop_V001`

As an example, the files that I would submit would be named:

- `SP24-MUSC-228_W03_P1-03_Daniel-Dehaan_Musical-Loop_V001`
