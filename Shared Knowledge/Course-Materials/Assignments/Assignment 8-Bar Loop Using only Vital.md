# Assignment: 8-Bar Loop Using only Vital

# Objective:

Compose an 8-measure using only [Vital](https://www.notion.so/Vital-Synth-18fdef2599674b63923d4d7058c489a0?pvs=21).

# Instructions:

Start by design the follow sounds in vital. Always start from the default (”initialized”) Vital.

- Kick
- Snare
- Hi Hat
- Bass
- Pad
- Lead

Then compose an 8-bar loop using only the 6 sounds you created from scratch in Vital.

When you are done, upload a .WAV file of your composition to this week’s discussion on Canvas and be prepare to present your DAW project in an upcoming class.

# Grading:

| Following Instructions | Only using the specified instruments and a clear attempt to make each of the required sounds. | 7 Points |
| --- | --- | --- |
| Creativity/Quality | Is there a clear intention to design sounds and compose music that work together in some sort of cohesive style. | 2 Points |
| X Factor | Does it have that “X” quality? | 1 Point |
|  | **Total Points:** | **10 Points** |
