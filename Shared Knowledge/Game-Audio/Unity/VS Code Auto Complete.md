If VS Code is not showing autocomplete suggestions here is what you need to do to fix it...

1. In your Unity Editor, navigate to `Window > Package Management > Package Manager`
2. In the left side bar, select Unity Registry and search for "Visual Studio Editor"
3. Click the "Install" button.
4. If VS Code is open, close and reopen the script (Quit VS Code, then double-click script in Unity's Project window).
