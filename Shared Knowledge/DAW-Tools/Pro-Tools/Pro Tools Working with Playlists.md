## Helpful Pro Tools Key Commands:

- Create new empty playlist: `control+\`
- Duplicate playlist: `command+\`
- Duplicate current playlist for **ALL** tracks `option+control+command+\`
- Copy Selection to Main Playlist: `control+option+v`
- Consolidate selected clips to single file: `shift+option+3`
- `P` and `;` move time selection up and down a track
- Solo current playlist `shift+s`
- Move keyboard focus (for keyboard shortcuts) to Groups window `command+option+3`

# Pro Tools - Exporting to Logic

1. See video above for exporting files via the Clips List.
2. Open Logic Project
3. Make sure SMPTE start time and tempo map matches Pro Tools session
4. Drag audio files for one instrument/microphone at a time into Logic session
5. Dialog box will open...choose “Create new tracks”
6. All the audio will be imported onto the different tracks
7. Select all imported audio files, then right click and select Move > Move to Recorded Position
8. With all the audio files still selected, right click on them again and choose Folder > Pack Take Folder

# Pro Tools - Exporting to Cubase:

1. See video above for exporting files via the Clips List.
2. Open Cubase Project
3. Make sure SMPTE start time and tempo map matches Pro Tools session
4. Drag audio files for one instrument/microphone at a time into Cubase session
5. Dialog box will open... (One track or different tracks) - Choose ONE TRACK
6. All the audio will be imported onto the one track, but in consecutive order.
7. Edit > Move to... > Origin (this will move all the regions to their correct timestamp layered over each other)
8. Open Lanes on the track. All the regions are on ONE Lane.
9. Right-click on the audio track and select 'Clean up Lanes'. All you audio should now be separated by lanes.
