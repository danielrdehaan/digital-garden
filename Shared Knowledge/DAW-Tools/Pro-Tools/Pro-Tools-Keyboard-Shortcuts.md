# Pro Tools Keyboard Shortcuts

A comprehensive reference for Pro Tools on macOS. Shortcuts marked with an asterisk (*) are particularly useful for media composers working to picture.

---

## Transport

| Action | Shortcut |
|--------|----------|
| Play / Stop | `Space` |
| Record | `⌘ Space` (with track armed) |
| Record (destructive) | `⌘ ⌃ Space` |
| Return to session start | `Return` |
| Go to end of session | `⌥ Return` |
| Rewind | `1` (numpad) |
| Fast forward | `2` (numpad) |
| Play from selection start | `⌥ [` |
| Play to selection end | `⌥ ]` |
| Half-speed playback | `⇧ Space` |
| Loop playback on/off | `⌘ ⇧ L` |
| Pre/post roll on/off | `⌘ K` |
| Online (sync to timecode)* | `⌘ J` |
| Wait for note | `F11` |

## Key Modifiers Reference

|----------|--------|------------|
| Command | `⌘` | Primary shortcut modifier |
| Option | `⌥` | Alternate/all/copy functions |
| Shift | `⇧` | Extend, add, or secondary action |

---

## Tips

- **Enable standard function keys:** System Settings → Keyboard → Function Keys → enable "Use F1, F2, etc. keys as standard function keys" (or use Fluor for per-app switching)
- **Lock tools:** Options → Edit/Tool Mode Keyboard Lock (prevents cycling through tool variants)
- **Numpad shortcuts:** Many Pro Tools shortcuts require a numeric keypad. Consider an external numpad for laptops.
