# Cost Breakdown of a College Class

# The Cost of Our Time: College Class Value Analysis

Understanding the monetary value of time spent in class can provide perspective on educational investment. This analysis breaks down the cost per minute for a single credit class.

## Basic Information

| **Full Year Tuition** | $37,344 |
| --- | --- |
| **Credit Load** | 18 credits |
| **Class Credits** | 1 credit |
| **Class Sessions** | Twice per week |
| **Session Duration** | 1 hour and 20 minutes (80 minutes) |

## Cost Calculations

### Step 1: Calculate cost per credit

```python
cost_per_credit = total_tuition / total_credits
cost_per_credit = $37,344 / 18
cost_per_credit = $2,074.67

```

### Step 2: Determine total class time in a semester

Assuming a standard 15-week semester:

```python
sessions_per_semester = 2 sessions/week × 15 weeks = 30 sessions
total_minutes = 30 sessions × 80 minutes/session = 2,400 minutes

```

### Step 3: Calculate cost per minute

```python
cost_per_minute = cost_per_credit / total_minutes
cost_per_minute = $2,074.67 / 2,400
cost_per_minute = $0.86

```

## Perspective

At $0.86 per minute, every:

- 5 minutes spent distracted costs $4.30
- 10 minutes scrolling on your phone costs $8.60
- Full missed class costs $69.16
