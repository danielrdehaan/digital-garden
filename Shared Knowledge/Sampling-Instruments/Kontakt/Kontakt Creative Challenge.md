# Kontakt: Creative Challenge

# Challenge

Using only the samples provided below create a custom Kontakt instrument. The resulting instrument can be any sound type: melodic, harmonic, percussive, soundscape, etc. The instrument should have a custom performance view with all of the following elements:

- Custom Wallpaper
- Custom Instrument Icon
- At least one custom control (e.g. slider, knob, button) for “morphing” the sound of your instrument

# Provided Materials

- [CCC_Experimental-Cello_Samples](https://www.dropbox.com/scl/fi/3mq6e4qmstxfuv2gvijtv/CCC_Experimental-Cello.zip?rlkey=8b1jb8jrkl519de0c2s7os82p&st=6mtkbmzo&dl=0)

# Submission

When your finish building your instrument please create a `.zip` folder containing the:

- `.nki` instrument file
- `.nkr` resource file
- A folder with all the samples compressed as `.ncw` file

**Submit your final instrument [here](https://www.dropbox.com/request/TISZdfo42FCIb1N9qOKu).**

# Resources

This is an “open book” challenge. So please use all resources available to you including your classmate and your instructor. You may find the following resource a good place to start as well as the Kontakt KSP Reference Manual available via the “Help” menu in all versions of Kontakt.
