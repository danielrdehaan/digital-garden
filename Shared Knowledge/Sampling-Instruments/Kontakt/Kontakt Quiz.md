# Instrument Specifications:

## 6 Groups:

- NormalRR1
- NormalRR2
- NormalRR3
- BendRR1
- BendRR2
- BendRR3

## Ranges:

- Instrument’s Pitch Range = A2-A3
- “Soft” velocity = 1-30
- “Medium” velocity = 31-95
- “Loud” velocity= 96-127
- Specific Note Ranges:
    - C3 = A2-C3
    - D3 = C#3-D3
    - E3 = D#3-E3
    - G3 = F3-G3
    - A3 = G#3-A3

## Keyswitches:

- Normal = C2
- Bends = D2
- In **Instrument Options** set the *Default Keyswitch* to C2

## Modulation:

- Each group’s *Volume* should be modulated by...
    - An AHDSR Envelope
    - Velocity

## Instrument Insert Effects:

- Slot 0: Replika Delay
