# Dan's Digital Garden

A shared knowledge base for students containing course materials, tutorials, one-sheets, and learning resources for audio production and game audio.

---

## Getting Started

### What You'll Need

1. **Obsidian** (free) — [Download here](https://obsidian.md/)
2. **GitHub Desktop** (free) — [Download here](https://desktop.github.com/)
3. **A GitHub account** — [Sign up here](https://github.com/)

### Step 1: Request Access

Email me at my Columbia email address with the email you used to register for GitHub. I'll send you an invitation to collaborate on the repository.

### Step 2: Accept the Repository Invitation

Once you receive an email invitation to collaborate on this repository, click the link to accept. This gives you access to clone and contribute to the repo.

### Step 3: Clone the Repository

1. Open **GitHub Desktop**
2. Go to **File → Clone Repository**
3. Select the **URL** tab
4. Paste: `https://github.com/danielrdehaan/digital-garden`
5. Choose where to save it on your computer (remember this location!)
6. Click **Clone**

GitHub Desktop will download the repository to your computer. This may take a moment if there are media files.

### Step 4: Open as an Obsidian Vault

1. Open **Obsidian**
2. Click **Open folder as vault**
3. Navigate to the `digital-garden` folder you just cloned
4. Select the folder and click **Open**

You should now see the vault contents in Obsidian's file explorer.

## Syncing Changes

### Pulling Updates (Getting New Content)

Before you start working, always pull the latest changes:

1. Open **GitHub Desktop**
2. Make sure `digital-garden` is selected as the current repository
3. Click **Fetch origin** (top bar)
4. If there are updates, click **Pull origin**

### Pushing Changes (Sharing Your Work)

If you've made changes you want to share:

1. Open **GitHub Desktop**
2. You'll see your changed files listed on the left
3. Write a short summary of your changes in the **Summary** field (e.g., "Added notes for Week 3")
4. Click **Commit to Main**
5. Click **Push origin** to upload your changes

### Avoiding Conflicts

- **Always pull before you start working**
- **Push your changes when you're done**
- If you see a merge conflict, ask for help — don't force anything

## Troubleshooting

### "I can't see my changes in Obsidian"
Make sure you pulled the latest changes in GitHub Desktop, then refresh Obsidian (close and reopen the vault if needed).

### "GitHub Desktop says there's a conflict"
Don't panic. Reach out for help before trying to resolve it yourself.

### "Obsidian looks different / missing features"
This vault doesn't include plugin configurations. You're seeing Obsidian with default settings, which is fine for reading content.

### "I accidentally deleted/changed something"
GitHub tracks all changes. In GitHub Desktop, you can right-click a changed file and select **Discard Changes** to undo. If you've already committed, reach out for help.
